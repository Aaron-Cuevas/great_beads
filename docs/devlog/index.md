# DevLog

One entry per step, named `YYYY-MM-DD-title.md` and listed under DevLog in `mkdocs.yml` (the docs build fails if an entry is left out). Each entry has five parts:

- **Context**: what was known before.
- **What changed**: code, data or setup.
- **Evidence**: numbers, figures, the commit.
- **Decisions**: what was chosen and why.
- **Next**: the step this one opens.
