# 2026-10-21 - Day 0, baseline and architecture

**Context.** The pipeline lives in one notebook (`waam_bead_morphology_7.ipynb`, sections 0 to 14) and the planner in one offline page (Bead Planner 2.0). Both work; neither can be tested piece by piece.

**What changed.** Repository created. Notebook v7 and planner 2.0 imported unchanged.

**Evidence.** Numbers the package has to reproduce: mass balance m = 0.6608 mm2 over 29 rows, RMSE 0.52 mm2; height law ln h = -0.382 + 0.520 ln A - 0.0301 (V - 18), rms 5.8 %.

**Decisions.**

1. Three commands (WFS, TS, V) and one observed variable (I), with a solver over relations R1 to R4 and three degrees of freedom. Current is not commandable on the R450 in this setup (notebook section 9). See [Architecture](../architecture.md).
2. The cross-section is a parabola, A = (2/3) w h, the shape the measurement in section 7 already assumes. The planner's cos2 goes.
3. Code, docs and this DevLog are written in English.
4. Docs live in `docs/` and publish to GitHub Pages by hand. The GitHub wiki is not used: it cannot run the planner's pages and is not versioned with the code.
